## 2. 项目：media-asset-cli

### 2.1 仓库里已有什么

> ⚠️ 以上只代表**仓库里有什么**，不代表**本人会写什么**。

### 2.2 理解债（当前最大的问题）

- 代码在跑、能提交，但每一行都不属于自己。债滚到 2027 年 = "简历上有项目、面试一问就塌"。
- **三条还债规则**：
  1. AI 生成的代码，commit 前要能**关掉屏幕讲一遍**；讲不清不许标"完成"。
  2. 每周只还**一笔**（一个函数），禁止"全部重学"。
  3. **新功能一律本人手写**；AI 只解释名词、只指出错误行，不代写。

### 2.3 本人真正理解的部分

- `MySQL.h` 每一行：构造 = 创建时连接、析构 = 销毁时关闭、`= delete` 防两个对象重复 `mysql_close`、`get()`、`conn_`、`host.c_str()`。
- `MYSQL*` 是连接句柄；`mysql_init` 返回指针；`try/catch`、`throw`、`e.what()`。
- 源码 → `.o` → 链接器 → CMake configure/build 这条链能讲通。
- 指针、引用、`const`、`nullptr` 的基本用法。

## 3. 能力盘点（结论）

- **广度不是问题，留存是问题。** 12 类覆盖（模拟 / 排序 / DFS / BFS / DP / 贪心 / 二分 / 前缀和 / 并查集 / MST / 最短路 / 数论），图论模板齐全，大一上属前 10–20%。P1219 八皇后是手写风格，不是模板。
- **形状是"题单式通过"**：85 → 105 → 50 的梯度，跟题单系统刷过，不是随机打野。
- **但全部是"单次调用"**：240 题里没有任何一类被调用过第二次。→ **知识面是借来的。**

**留存三档（本人自评校准后）**

| 档 | 内容 | 修复动作 |
|---|---|---|
| 大概率还在 | 模拟 / 排序 / DFS 回溯 / 贪心 / BFS | 直接用 |
| 热一下能回来 | 二分 / 前缀和 / 数论 / 字符串 / 高精度 / **背包 / 并查集 / 最短路**（记得原理、忘了实现） | **重写一遍实现**，不是看一遍 |
| 基本过期 | MST 细节 / 拓扑 / ST 表 / 网络流 / 线段树 | 重学一次模板 |

- **只认独立完成率**：关掉所有参考、从空文件写出来才算数；看题解过的题必须重写一遍才能勾掉。

### 7.2 执行对话

- 一次只解决一个问题：一个函数、一个报错、一个知识点。

- **不代写实现**，除非我明确说"直接帮我改"。

- 不要默认我会 `class`、`STL`、`CMake`、`Git`。
